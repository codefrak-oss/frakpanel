A tile allowed to rearrange the panel's slots

Status: proposed · Ticket #23

The question

Should a registered tile (say, in the middle slot) be able to put its own "left" and "right" pages into slots 0 and 2 on a tap, within about a second, only if its registrant allowed it, even when its server cannot reach edged?

Today, without any change

edged.py:358 sends Access-Control-Allow-Origin: * on every reply and do_OPTIONS (edged.py:401-405) allows POST, so any tile page in the kiosk browser can already POST /slot, with no permission. The shell polls /layout every 2 s.

Proposal: B, gate the browser path by Origin

Options

A. Tile server contract, long-polled by edged

The tile server exposes a layout-requests endpoint edged long-polls (through the relay for laptops). Can't reach URL tiles without a cooperating server; still needs B's gate.

B. Page calls POST /slot, gated by the permission (recommended)

Keep today's browser path; edged maps the request's Origin to a registered tile and allows it only with arrange and while it sits in a slot. Works for all three routes; the server never needs a route to edged.

C. Layout op on the relay control connection

New layout and tiles ops on edgerelay.py's outbound control link. Relay tiles only; still needs B's gate.

D. Build nothing yet

Any tile page keeps setting slots with no permission.

Principles

"No auth anywhere" stays true: the flag is a guard against a misbehaving tile, not auth (curl can still set slots); TILES.md gains one line. "The host never knows what a button means" is kept: edged only hears "URL X in slot N".

Open questions

  • Registrant-only permission, or also revocable from the picker? Assumed registration only.
  • Must the requesting tile be in a slot? Assumed yes.
  • May a permitted tile use POST /layout as well as /slot? Assumed both.

Implementation outline

  1. mcp_tiles.py: register_tile takes arrange, stored in mcp_tiles.json.
  2. edged.py: local_tiles.json arrange; GET /tiles reports it.
  3. edgerelay.py: --may-arrange in hello, persisted in edge_relays.json.
  4. edged.py: Origin gate on /slot and /layout, 403 otherwise.
  5. edged.py: shell long-polls /layout?since=.
  6. examples/demo_tile.py: left/right demo.
  7. TILES.md and README docs.
  8. Tests for gate, persistence, MCP field, /tiles field.
